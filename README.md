# The Smiths Archive 🎸

Um espaço para conhecer a história do The Smiths, explorar seus álbuns e descobrir quais deles mais combinam com suas preferências musicais.

## 📖 Sobre o projeto

O **The Smiths Archive** é um site interativo desenvolvido com o objetivo de apresentar a banda britânica The Smiths e aproximar novos ouvintes de suas músicas.

O projeto reúne informações sobre a história da banda e seus álbuns, além de oferecer uma experiência personalizada baseada nas preferências musicais de cada usuário.

## 🎯 Objetivo

Incentivar os usuários a conhecerem o The Smiths, explorando sua trajetória, seus álbuns e suas características musicais. A proposta é conectar cada visitante com músicas que combinem com seus gostos e sentimentos, tornando a descoberta da banda mais interessante e pessoal.

## 👥 Público-alvo

O site é destinado a pessoas que gostam de música, especialmente de rock alternativo, indie e post-punk, além de ouvintes que desejam conhecer melhor o The Smiths.

## ✨ Funcionalidades

- **Página inicial:** apresenta a história da banda e informações sobre sua trajetória musical.
- **Cadastro:** permite que novos usuários criem uma conta.
- **Login:** possibilita que usuários acessem a área personalizada do site.
- **Questionário musical:** coleta informações sobre as preferências musicais dos usuários.
- **Dashboard personalizado:** apresenta recomendações de álbuns do The Smiths de acordo com as respostas do questionário.
- **Gráfico de recomendações:** utiliza uma visualização em gráfico de barras para facilitar a comparação entre os álbuns recomendados.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e identidade visual do site.
- **JavaScript:** implementação das interações e da lógica das funcionalidades.
- **Chart.js:** criação do gráfico de barras do dashboard.
- **API web-data-viz:** integração com a aplicação para operações relacionadas aos dados do projeto.

## 🎨 Identidade visual

A identidade visual foi inspirada na estética dos álbuns do The Smiths, buscando transmitir uma atmosfera vintage, melancólica e minimalista.

A paleta de cores utiliza tons neutros, como bege, cinza e grafite, enquanto as fontes **Cormorant Garamond** e **Libre Franklin** ajudam a combinar uma aparência editorial com boa legibilidade.

## 🚀 Como executar o projeto

1. Clone este repositório para sua máquina.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra a página inicial do projeto utilizando um servidor local, como a extensão Live Server do Visual Studio Code.
4. Navegue pelas páginas e explore as funcionalidades disponíveis.

**Observação:** a execução completa depende da configuração da API e dos serviços utilizados pelo projeto.
